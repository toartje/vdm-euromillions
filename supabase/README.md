# LuckyPool Supabase schema

Dit bestand hoort bij de eerste database-opzet van LuckyPool.

## Tabellen

- `groups`: de EuroMillions-groep zelf
- `members`: de mensen in de groep
- `contributions`: de bijdragen die leden storten

## Wat nog niet zit in deze fase

- trekkingen
- betalingen
- winstverdeling
- ticketuploads
- login en rechten

## Volgende stap

Plak `schema.sql` in de Supabase SQL Editor en voer het uit, of gebruik het als basis voor een migration.
